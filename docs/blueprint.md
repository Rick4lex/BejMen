# **App Name**: Turno Maestro

## Core Features:

- Shift Management Dashboard: Display a spreadsheet-like dashboard for managing shifts, showing data such as time, client, messenger, and notes with Markdown support.
- Filtered Shift Views: Implement a filtered view for the current or selected week and day, focusing on the shifts scheduled for those specific times.
- Messenger Assignment UI: Enable manual input or suggestions for messenger assignments.
- AI-Powered Shift Suggestions: Use generative AI as a tool to provide suggestions for optimal shift assignments based on messenger availability, location, and other constraints.
- Messenger-Centric Dashboard: Allow admins to view the dashboard per messenger to easily see the week's shifts.

## Style Guidelines:

- Primary color: Golden tone (#D4A276) to evoke a sense of reliability and warmth, aligning with earthy tones from the company's color palette.
- Background color: Very light desaturated earthy tone (#F2EFE9) to create a soothing backdrop that doesn't distract from the data-rich interface.
- Accent color: Blue (#73A7C9), used sparingly to highlight key interactive elements such as call-to-action buttons.
- Font: 'Montserrat' sans-serif. Note: currently only Google Fonts are supported.
- Spreadsheet-like layout for the main dashboard with subtle borders, optimized for desktop and mobile responsiveness.
